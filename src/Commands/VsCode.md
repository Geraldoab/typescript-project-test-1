## Commands

### Show a side-by-side preview

`ctrl + K V`

### Add a default formatter

`winget install EsbenPetersen.prettier-vscode`

Create a .prettierrc file in your project root and tell it your preference

`{
  "singleQuote": true
}`

Press Ctrl + , to open your VS Code settings, search for "Format On Save", and check the box. You should also search for "Default Formatter" and select "Prettier - Code formatter" from the dropdown menu.
